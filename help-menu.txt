🔍 Search Movies by Title, Release Year, Genre, or IMDb ID
  Format: search {title, year, genre, imdb} [text]
  ✅ Examples:  
  - 🔎 search title Avatar 
  - 🎞️  search year 2010 

  📝 Shortcut for Title Search: 
    Format: ? [title]  
    ✅ Example: ? Avatar

🎭 Explore All Genres! 
  *Command: genres

📌 View Movie Details from Search Results
  Format: info [search results id]
  ✅ Example: info 1 

_____________________________________________________________________________________________________________

📊 Sort Search Results 
   - 🔠 By Title  → Alphabetical Order  
   - 📅 By Year   → Descending Order  
   - ⭐ By Rating → Descending Order  

  Format: sort {title, year, rating}
  ✅ Example: sort year

_____________________________________________________________________________________________________________

🎭 Filter Search Results
  - 📅 By Year 
  - ⭐ By Rating 
  - 🎞️  By Genre  

  Format: filter {year, rating, genre} [text]  
  ✅ Example: filter year 2012

🌟 Create Your Own Watchlist

  1. Create a New List
   📌 Command: list new [name of the list] 

  2. Add Items to the List
   🎮 Command: list add [id of the movie]

  3. View Items in the List
   👀 Command: list show  

  4. View All Created Lists  
   📂 Command: list all
